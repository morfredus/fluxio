# Fluxio 0.1.0-alpha.19 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

CSV exports now ask which column separator to use: comma (standard CSV, numbers with a decimal point, the default) or semicolon (French-language Excel, numbers
with a decimal comma so Excel reads them as numbers). The last choice is offered again next time; "Cancel" stops the export. Applies to table exports and the
accountant's journals.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Les exports CSV demandent maintenant le séparateur de colonnes : virgule (CSV standard, nombres avec le point, proposée par défaut) ou point-virgule (Excel en
français, nombres avec la virgule décimale pour qu'Excel les lise comme des nombres). Le dernier choix est reproposé la fois suivante ; « Annuler » interrompt
l'export. Concerne les exports de tableaux et les journaux pour le comptable.
