# Fluxio 0.1.0-alpha.17 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

New filters above the left-hand list: a "Not yet validated only" check box (unchecked: every file; checked: only those not yet saved in the database) and a
button to hide or show the "Information" documents (letters, contracts, delivery slips... read but set aside). They can be combined. Nothing is removed from
the list: only the display changes.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Nouveaux filtres au-dessus de la liste de gauche : une case « Seulement les non validés » (décochée, tous les fichiers ; cochée, seulement ceux pas encore
enregistrés dans la base) et un bouton pour masquer ou afficher les documents « Information » (courriers, contrats, bordereaux… lus mais mis de côté). Les
deux se combinent. Rien n'est retiré de la liste : seul l'affichage change.
