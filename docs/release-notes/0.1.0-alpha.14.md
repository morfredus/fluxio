# Fluxio 0.1.0-alpha.14 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

PDFs added to the left-hand list but not yet validated are now back in the list the next time you start Fluxio, so you do not have to import them again.
A file moved or deleted in the meantime is simply skipped.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Les PDF ajoutés à la liste de gauche mais pas encore validés réapparaissent au lancement suivant de Fluxio : inutile de les réimporter.
Un fichier déplacé ou supprimé entre-temps est simplement ignoré.
