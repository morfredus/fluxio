# Fluxio 0.1.0-alpha.1 (alpha)

## English

**Alpha release**: not yet used on live accounts, double-check the figures and keep your PDFs and `fluxio.db` safe.

First standalone version of Fluxio, a Windows application that reads the PDFs of a bar / tobacconist / lottery / betting /
hotel business (cash-register Z reports, supplier invoices, bank statements, lottery commission invoices and settlement
statements), shows what it understood so you can correct and validate it, stores everything in a local SQLite database and
reconciles cash, bank, invoices and the weekly lottery settlement.

Portable build: unzip and run `Fluxio.exe`. Your data lives in `%APPDATA%\Fluxio\fluxio.db`, outside the program folder, so
updating never touches it. The executable is not code-signed: Windows SmartScreen may warn on the first run.

## Français

**Version alpha** : pas encore utilisée en conditions réelles, vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Première version autonome de Fluxio, application Windows qui lit les PDF d'un commerce bar-tabac-FDJ-PMU-hôtel (Z de caisse,
factures, relevés bancaires, factures de commissions et relevés d'opérations FDJ), propose ce qu'elle a compris pour que vous
corrigiez et validiez, enregistre tout dans une base SQLite locale et rapproche caisse, banque, factures et règlement
hebdomadaire FDJ.

Version portable : dézipper et lancer `Fluxio.exe`. Les données sont dans `%APPDATA%\Fluxio\fluxio.db`, hors du dossier du
programme : une mise à jour n'y touche jamais. L'exécutable n'est pas signé : SmartScreen peut avertir au premier lancement.
