# Fluxio 0.1.0-alpha.11 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

Scanned-document recognition (Windows OCR) no longer crashes when run outside the application (test scripts). The fictitious test document set is much larger
(FDJ statements and commission invoices, PMU account, customs bulletin, a daily Z for two months) for testing every screen. No change to how the program reads your documents.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

La reconnaissance des documents scannés (OCR de Windows) ne plante plus quand elle est lancée hors de l'application (scripts de test). Le jeu de documents fictifs
