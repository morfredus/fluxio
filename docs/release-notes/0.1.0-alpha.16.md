# Fluxio 0.1.0-alpha.16 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

When you add a PDF whose content is already in the list, the message now says which file it matches ("Already in the list: x.pdf (same content as y.pdf)")
and selects that file. Two PDFs with exactly the same content are counted once, even under different names.

New "Quit" button at the right end of the menu bar.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Quand vous ajoutez un PDF dont le contenu est déjà dans la liste, le message dit maintenant avec quel fichier il correspond (« Déjà dans la liste : x.pdf
(même contenu que y.pdf) ») et sélectionne ce fichier. Deux PDF au contenu strictement identique ne sont comptés qu'une fois, même sous des noms différents.

Nouveau bouton « Quitter » à l'extrémité droite de la barre de menu.
