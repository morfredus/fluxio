# Fluxio 0.1.0-alpha.15 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

Fix: deleting a document from the database (right-click in the list, File menu, or "Saved documents") now also removes it from the left-hand list; it used
to stay there with only its check mark gone. A document that is not in the database (information, error, not yet validated) is simply taken off the list
instead of showing an error message.

Since alpha.9: Windows installer next to the portable zip (alpha.10); larger fictitious test set (alpha.11); the "Validate and save" button is back in front of
a loan schedule (alpha.12); the window refreshes after a deletion, removal or restore (alpha.13); documents added but not yet validated come back in the list at
the next start (alpha.14).

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Correction : supprimer un document de la base (clic droit dans la liste, menu Fichier ou « Documents enregistrés ») le retire aussi de la liste de gauche ;
avant, il y restait et seule sa coche ✔ disparaissait. Un document qui n'est pas dans la base (information, erreur, pas encore validé) est simplement retiré
de la liste, sans message d'erreur.

Depuis l'alpha.9 : installateur Windows en plus du zip portable (alpha.10) ; jeu de documents de test fictifs plus complet (alpha.11) ; le bouton « Valider et
enregistrer » revient devant un tableau d'amortissement de prêt (alpha.12) ; la fenêtre se met à jour après une suppression, un retrait ou une restauration
(alpha.13) ; les documents ajoutés mais pas encore validés réapparaissent au lancement suivant (alpha.14).
