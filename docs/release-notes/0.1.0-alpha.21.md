# Fluxio 0.1.0-alpha.21 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

Start-up: the Fluxio window now takes focus and comes to the front once loaded, even if you clicked elsewhere during the loading screen (it could open behind other
windows, with only the taskbar icon flashing). Windows does not let an application steal focus, so the window is briefly set "always on top", then back to
normal, and activated.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Lancement : la fenêtre de Fluxio prend le focus et passe devant les autres une fois chargée, même si vous avez cliqué ailleurs pendant l'écran de chargement (elle
pouvait s'ouvrir derrière, avec seulement l'icône qui clignotait dans la barre des tâches). Windows interdit à une application de voler le focus : la fenêtre est
brièvement placée « toujours au-dessus » puis remise normalement, et activée.
