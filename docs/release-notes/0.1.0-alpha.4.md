# Fluxio 0.1.0-alpha.4 (alpha)

## English

**Alpha release**: double-check the figures and keep your PDFs and `fluxio.db` safe.

New in this version: everything already saved is available at startup (the reconciliation screens, the weekly lottery settlement,
account tracking, cash position and statistics start from the whole database, no PDF to reload); a "History" menu to search all the
recorded activity whatever the year (text, exact amount or range, day or period, nature); renaming a document's file from Fluxio
with a suggested name; supplier autocompletion; new documents (Keolis / TBM invoices, SED statement-invoices paid by LCR, parcel
relay payment notices treated as receipts); a warning when the amount in a file name differs from the amount read; a Windows taskbar
identity and multi-size icon; code clean-up and automatic formatting.

## Français

**Version alpha** : vérifiez les chiffres et gardez vos PDF et `fluxio.db` en sécurité.

Nouveautés : tout ce qui est enregistré est disponible dès le démarrage (les écrans de rapprochement, le règlement FDJ de la semaine,
le suivi par compte, la trésorerie et les statistiques partent de toute la base, sans recharger de PDF) ; un menu « Historique »
pour rechercher dans toute l'activité enregistrée, quelle que soit l'année (texte, montant exact ou fourchette, jour ou période,
nature) ; renommage du fichier d'un document depuis Fluxio avec un nom proposé ; autocomplétion du fournisseur ; nouveaux documents
(factures Keolis / TBM, factures relevés SED réglées par LCR, avis de virement du relais colis traités comme des encaissements) ;
alerte quand le montant du nom de fichier diffère du montant lu ; identité Windows et icône multi-tailles ; nettoyage du code et
formatage automatique.
